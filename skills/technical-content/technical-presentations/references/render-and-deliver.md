# 演示文件的实现、渲染与检查

## 媒介选择

- 需要沿用既有 PowerPoint 模板、人工继续编辑时使用 PPTX；关注文字框、字体、图形层级和原有主题的保留。
- 需要键盘导航、交互分步或浏览器展示时使用 HTML；应考虑离线资源、焦点、减少动态效果和打印出口。
- 用户只需静态阅读或归档时，按实际需要导出 PDF；检查页数、页边距、字体及分步动画失去交互后的完整性。

实现之前确认目标设备/画幅，不将其他项目 1920x1080 的 CSS 设计尺寸作为必然要求。没有相应工具时不虚称完成导出。

## 真实检查

以实际渲染的标题页、普通信息页及最复杂图表页检查：在正常阅读尺寸下能读清文字、图例与公式；页内没有遮挡或裁切；图/表与文字表达同一证据；页面间颜色和名称稳定。HTML 还检查首尾导航、键盘焦点、脚本错误、本地资源、手机或小视口的实际效果；PDF 再核对静态每页与原页面数的关系。

检查脚本可发现缺失资源、无效引用或结构错误，但不能证明内容科学正确或读者理解充分。用户对具体页面的直接反馈应作为迭代依据。保留可编辑文件和可重建的来源，不把渲染截图当作唯一交付。
