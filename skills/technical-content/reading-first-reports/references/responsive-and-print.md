# 响应、可访问性与静态交付

## 自适应文档

窄屏应重新排布正文与图文，而非把整个桌面画布缩小。保持适当行宽。宽表用局部横向滚动并保留行列标题；图片需要完整标签、图例和替代说明。页面不应因一个代码块造成整体横向滚动。

## 渐进增强

先提供完整语义正文，再加入目录高亮、筛选、折叠或交互数据视图。必要证据不得只在悬停或脚本执行后出现。折叠控件必须支持键盘、清楚的展开状态和触屏；动画尊重系统减少动态效果设置。关闭 JavaScript 后主结论、资料来源与章节锚点仍应存在。

## 打印和 PDF

打印样式隐藏非必要控件，保留编号、引用、图表、公式与必要展开内容。对长表检查表头与分页；对图片检查裁切；对代码块检查截断；对标题检查孤立单行。实际渲染 PDF 后逐页检查，不把“有 print CSS”视为已经完成导出验证。不同媒介可能省略交互探索，但要说明省略项并保留基本结论。

## 核查清单

检查摘要与正文一致；目录、深链接刷新、交叉引用可到达；桌面与手机仍可读；键盘和焦点可操作；关闭脚本不丢失主要信息；实际导出 PDF 后检查页数、分页及图注。浏览器构建完成只说明技术出口可运行，不证明引用与事实正确。

参考：https://www.w3.org/TR/WCAG22/ ；https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_media_queries/Printing ；https://quarto.org/docs/output-formats/pdf-basics.html 。
