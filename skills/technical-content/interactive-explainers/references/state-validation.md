# 交互状态验证与可访问性

## 状态与不变量

对每个关键控件检查默认、两端、代表中间值、非法值、快速连续改变、连续重置、模式切换和任务中断。数值、文字和图形都应由同一计算结果生成。对概率分布检查归一性，对索引检查边界，对几何量检查其有效域。控件的 min/max 属性不能代替底层输入验证。

## 可访问输入与反馈

优先原生表单控件配可见标签，提供键盘和触摸路径、焦点指示和一致的重置行为。变化通过文字、形状和位置等多重信号呈现，避免只用颜色。动态播报只用于关键结论，不因高频帧产生阅读器噪声。

## 动画与降级

遵循 `prefers-reduced-motion`，使用静态或即时状态切换保留主要机制。静态文字、公式或表格应能独立说明因果与边界。随机数需要固定种子、范围与复现方式，或明确随机输出只作探索示意。

## 实际浏览器核查

在当前目标浏览器执行边界状态，检查控制台错误、可见数值、键盘焦点、触摸操作、缩放与小屏溢出。静态截图不能证明状态更新正确。没有运行环境时报告已做的静态检查，不虚称完成交互验证。
