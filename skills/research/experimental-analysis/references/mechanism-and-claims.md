# 机制分析、反例与可使用的结论

## Agentless 补丁选择消融

[Agentless FSE 2025](https://lingming.cs.illinois.edu/publications/fse2025.pdf) Table 4 在 SWE-bench Lite 300 个 Issue 上报告：多数投票 77 个修复，增加回归测试为 81 个，再增加复现测试为 96 个。新增步骤对应约 +1.33 和 +5.00 个百分点。表中附加成本是补丁选择阶段的增量平均费用，不能写成整套系统的总成本。

这组聚合数据支持所测流程中增加筛选阶段与修复数上升的观察；它不能仅凭三个总数证明每个 Issue 的配对显著性，也不能独立分离生成候选与筛选算法的全部因果作用。需要原始逐任务候选和测试轨迹时，应说明证据缺口。

## 从描述到主张

对每个 RQ：描述观察值与比较条件 → 给出效应和不确定性 → 解释任务意义 → 核查机制与替代解释 → 定义允许主张和反例。若子群结果和整体趋势相反，应核查样本量、选择条件和统计结构，避免事后选择最有利配置。

`支持主张`不等于`证明机制唯一`；一个代表性成功案例说明流程可能有效，但没有逐类统计时不能宣称该类任务均会获益。保留可信负结果和成本权衡，提供可以实际写进论文且不夸大的结论。
