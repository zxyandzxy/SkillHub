# 修订稿的独立复核

## 保留原问题

读取初稿、原评论、修订稿和作者回复。每项问题保留原始含义、严重性及其成立证据。作者写“已修复”属于声称；审查应回到实际改动和新增证据。

## 分类

- 已解决：原科学或解释缺口得到实质处理，证据可检查。
- 部分解决：有新增材料，但决定性问题仍存在。
- 未解决：核心缺口没有有效变化。
- 被替代：研究范围或协议正式改变，需要说明为何旧问题不再适用及产生的新限制。

比较时检查新旧术语、数字、图表、论文主张以及回复与实际修改是否一致。一个问题解决后可能引入新矛盾，应单独定位。不要把修订复核变成与旧问题无关的新一轮无边界全面审稿。

## 审查边界

不要求机械接受所有外部意见；意见可能基于误读或错误前提，需要从论文和证据核查。修改研究问题、追加正式实验或公开未发布稿件仍需作者明确授权。独立 Agent 意味着采用独立的审查视角，并不构成真正的学术同行评议。

参考：https://publicationethics.org/resources/guidelines/cope-ethical-guidelines-peer-reviewers 。
