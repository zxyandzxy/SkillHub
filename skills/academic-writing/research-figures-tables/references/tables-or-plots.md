# 定量图和 LaTeX 表格：选择、统计语义与制作

## 让表达形式对应阅读任务

| 读者需要判断 | 优先考虑 | 注意条件 |
| --- | --- | --- |
| 少量离散配置下的精确值及多指标 | 紧凑表格 | 对齐单位、指标方向、样本与分组 |
| 随时间、序列长度、轮次变化的趋势 | 折线或分面图 | 横轴必须是真正有序的量；缺失点不能直接连成观测 |
| 多方法的大小差异或配对变化 | 点图、区间图、必要时分组柱状图 | 明确基线、方向、效果量和不确定性 |
| 一组任务的分布、异常值 | 箱线、散点分布、直方图等 | 对独立样本单位和聚合方式作说明 |
| 参数与指标形成二维矩阵 | 热力图 | 定义色标方向，缺失单独编码 |
| 模块是否有益、不同机制的消融 | 消融表或对照图 | 每行真实配置必须可还原 |

连续趋势并非天然优于表格；当读者重点是查找精确配置与数值时，表格通常信息密度更高。只因图像视觉醒目而绘制重复结果会占用版面并掩盖新的信息。

## 合法比较与统计信息

- 区分相对增幅与百分点变化；注明提高多少、基于什么分母和参照。
- 明确指标“越大越好”或“越小越好”，以及单位、精度、样本数和数据集版本。表中的最佳值仅对同条件合法比较加粗。
- 只有确实存在重复运行或统计模型时才可绘制 SD、SE、置信区间或显著性标记，并说明独立重复单位。多候选补丁/多张切片不自动成为独立样本。
- 失败、OOM、未测、缺失、不适用、真实零分别编码。图中留空也需要让读者了解原因。
- 柱状图通常以零作为长度基准。截断坐标轴、双纵轴、面积夸张和未经解释的归一化会改变视觉判断；确有科学需要时必须清楚标注。
- 对涉及多个不同条件的比较，先确定哪些可共享坐标，必要时按设备、head dimension、mask 或模型规模分面，而不是混合得出“总体最快”。

## LaTeX 表格

1. 在表头明确模型、条件、指标、单位与指标方向；配置的关键信息不能全部移入正文使表格失去独立可读性。
2. 使用 `booktabs` 的少量横线和明确分组；可用 `siunitx` 或等价方式保证数字对齐。保留必要精度，不为了整齐擅自四舍五入科研数据。
3. 仅当多个表共享合法的比较维度且合并后仍清晰时才合并。表中的装饰性段落通常移到 Results；缺失值含义、符号、样本、单位仍需正式表注。
4. 实际编译 `.tex`，在目标单栏/双栏或跨栏尺寸查看，而不是仅检查源代码的排版命令。

## 实际论文数值示例

FlashAttention-2（ICLR 2024）Table 1 给出 GPT 风格训练吞吐，设备为 **8×A100 80GB SXM4**，单位为 **TFLOPs/s/GPU**：

| 模型与上下文 | 无 FlashAttention | FlashAttention | FlashAttention-2 |
| --- | ---: | ---: | ---: |
| GPT3-1.3B，2k | 142 | 189 | 196 |
| GPT3-1.3B，8k | 72 | 170 | 220 |
| GPT3-2.7B，2k | 149 | 189 | 205 |
| GPT3-2.7B，8k | 80 | 175 | 225 |

来源：<https://proceedings.iclr.cc/paper_files/paper/2024/file/98ed250b203d1ac6b24bbcf263e3d4a7-Paper-Conference.pdf>，Table 1。

当需要报告四组配置的准确数值，采用表格即可。当论文真正需要展示上下文增加时吞吐变化的形态，可以针对两种模型规模绘制分面图，但通常不同时重复放同一组数据的等价图表。原文数据没有提供逐配置重复试验的离散程度，不得添加自行猜测的误差条。这些数字是**端到端训练吞吐**，与 attention kernel 的微基准测试不同。

## 结果解释与交付

图表负责可读地展示数据，Results 正文负责解释其研究意义，不逐项复述所有单元格。若图表无法获得与原始结果一致的数值源，应暂停准确性定稿，并标明待核对项。

提供完整的 `.tex`、绘图脚本/数据及实际渲染文件。数值修改后重新生成，而非在 PNG/PDF 上覆盖数字。用户仅要求改变版式时，不调整实验协议或统计口径。
