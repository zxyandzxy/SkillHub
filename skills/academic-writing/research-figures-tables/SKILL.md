# 科研图表（Research Figures and Tables）

以研究问题、方法机制和实验证据决定图表的内容与形式。最终产物应准确、清楚、可编辑，并在目标论文的实际版面中可读。

## 确定任务与证据

1. 识别用户要求：规划整篇论文图表、研究参考论文、创建方法图/实例图、制作定量图/LaTeX 表格、修改已有图表，还是检查最终版面。已有明确局部任务时，不扩大为整篇论文重设计。
2. 读取相关主稿或已确定的研究问题、方法定义、原始结果、图表引用、已有样式与目标模板。优先复用可访问的权威文件；只向研究者确认会改变科学含义的未知事实。
3. 对每个候选视觉明确：它要回答的读者问题，所支撑的主张，证据位置，必须展示的变量/结构，以及与相邻图表的关系。整篇规划与去重见 [visual-planning.md](references/visual-planning.md)。
4. 学习形式时，优先检查当前论文最相关的已发表前作及其真实图表，再根据任务补充同类优秀论文；记录值得采用的具体结构和信息呈现方式。案例见 [published-paper-study.md](references/published-paper-study.md)。不复制受保护的图像或将参考论文的结果当成本研究数据。

## 选择和制作

1. 根据阅读任务选择表达：解释输入/输出与状态使用实例或方法图；比较有限离散配置并精确查值使用表格；比较趋势、分布、关系或不确定性使用合适的定量图。若图表不能增加新的读者信息，优先删除或合并。详见 [tables-or-plots.md](references/tables-or-plots.md)。
2. **方法图**：核实算法和系统的输入、输出、状态、数据流、控制流、维度、约束及对照关系。保持新旧方法的符号、尺度和布局可对应，重点突出真实变化；区分已实现步骤与假设性设计。工具选择和预览见 [diagram-tools-and-previews.md](references/diagram-tools-and-previews.md)。
3. **定量图与表**：从原始数据或可核查的正式来源生成，保留比较配置、指标定义、单位、样本/分母及统计口径。不同数据集、设备、模型、精度或实验协议不可暗中混为同一条件；未测、失败、OOM、不适用和实际零值须区分。没有重复实验或不确定性估计时，不补造误差条和显著性符号。
4. 优先使用可编辑、可重新生成的源文件：绘图脚本和数据、SVG/TikZ/Graphviz/draw.io 文件、LaTeX 表格等。生成式图像可以辅助探索非证据性的视觉方案，但不能作为精确数值、公式或架构图的权威来源。
5. 统一同一论文中的术语、方法顺序、颜色含义、线型、标记、单位与数值精度。表格只保留必要比较维度；图注解释对象、条件、符号和读法；结果意义与原因由正文论证，不在图表里堆放说明段落。

## 真实呈现、核验与交付

1. 当任务涉及图形方案或表格排版判断时，**实际渲染并展示成果**，例如把 LaTeX 表编译成图片、把 SVG/绘图代码导出为 PNG/PDF。用户需要选择两种形式时才制作两份完整备选，不默认重复绘制相同数据。
2. 把图表放入目标论文的单栏、双栏或跨栏环境，以实际阅读尺寸检查文字、公式、图例、箭头、间距、裁切、灰度辨识和多面板顺序；遵守目标场合当前要求，不能套用其他期刊的固定字号。详见 [publication-qa.md](references/publication-qa.md)。
3. 从权威数据或图形源核对每个重要数字、坐标、维度及连线，检查正文、图注、引用编号和实验条件一致。修改数据后重新运行生成过程，不在旧导出图上手工改数字。
4. 交付可查看的实际渲染图、完整可编辑源及重建所需的数据或出处和步骤。若受保密或版权限制不能提供原始材料，明确可复现的范围；没有实际检查的部分如实说明。
5. 仅在用户允许的范围内修改正式论文；涉及研究主张、方法拓扑、指标计算方式或实验结论的实质性变化，交由研究者决定。完成的是图表工作时，不自动启动全文写作、重新分析实验或开展审稿。

与 `academic-writing` 的接口是**图表所支持的论证及与正文一致性**；实验分析口径由 `experimental-analysis` 或研究者确认。需要审查全稿引用/原始结果一致性时按需使用 `research-integrity-audit`，不在每张普通图表上执行全量审计。

许可及继承方法的原始归属见 [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md)。
