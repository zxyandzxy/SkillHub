# 个人数据生命周期与负面验证

## 隐私不等于数据加密

先问为何收集、哪些字段必须取得、用户是否知情、是否有替代方案。再核查默认配置、使用与共享对象、第三方外发、跨端与备份位置、保留、删除和用户控制。加密可以保护部分传输或存储风险，但不能证明过量采集合理。

## 负面场景

按真实功能选择未登录、访问他人对象、角色降级、被撤销共享、超长/恶意输入、路径绕过、敏感日志、删除后残留和外部传输等场景。确认拒绝在可信边界发生，错误与日志不泄露敏感内容。优先合成或脱敏数据。

## 证据与权限

静态扫描、依赖检查、配置核查、接口测试和专业评审是不同证据。没有发现告警不是无漏洞的证明。未经授权不得用真实数据测试在线第三方服务，不得施加生产破坏性负载。法律与合规判断需由适格人员确认。
