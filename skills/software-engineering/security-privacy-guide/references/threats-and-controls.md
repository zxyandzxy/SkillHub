# 威胁边界与控制选择

## 最小模型

列出资产与数据、允许的主体和操作、数据流、信任边界、可能的越权或泄露方式、拟采用的控制、实际验证路径和剩余风险。按任务风险控制深度，不为低风险文本修改机械制作完整框架。

## 不能替代的控制

认证只证明主体身份；授权决定其能否访问特定资源。前端隐藏按钮、随机文件 ID 或不公开接口地址都不能代替服务端资源权限。参数化 SQL 阻断注入但不能解决用户是否有权读该记录。输入合法性校验、HTML 上下文输出编码、路径限制和 URL 白名单分别对应不同风险。

## 秘密与依赖

最小权限、可信的秘密存储和安全日志。泄露凭据需检查撤销和轮换，删除提交中的明文不足以取消已发生的暴露。依赖告警须核对真正的版本、可达代码、修复方式与兼容影响。

## 参考框架

Web/API 使用 OWASP ASVS（当前稳定版应以官网核对），移动端使用 OWASP MASVS 与平台官方指南；桌面程序需关注本地文件与更新可信。不能把一种平台的所有条目当作另一平台的强制标准。
