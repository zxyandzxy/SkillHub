# 复现、边界调查与可证伪假设

## 实际行为与预期

先核对真实错误信息、调用场景与业务规则；记录复现步骤、输入、环境、相关配置和失败频率。最好最小化复现，但不能删去触发错误所需的系统约束。

## 第一处偏差

按用户输入、业务处理、依赖调用、数据层和外部输出追踪。边界日志需要回答：值是否到达，类型与编码是否正确，配置是否传递，在哪里首次改变，失败从哪层返回。对偶发问题区分时间、并发、网络与共享状态影响。

## 假设模型

“观察 A，推测 B；若 B 成立，实验 C 应得 D；若不成立则检查 E”。一次改变一个相关条件。有效实验应能排除至少一个竞争解释。避免反复调整多个超时和开关却不记录影响。

## 安全

禁止记录完整令牌、密钥、用户私人数据或连接字符串。增加观察点应可撤销，不默认关闭权限、验证、错误检查或生产告警。来源：https://sre.google/sre-book/effective-troubleshooting/ 。
