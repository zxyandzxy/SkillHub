# 会话恢复与离开步骤

## 恢复

核对项目身份和当前目录；读取最新快照；检查 `git status`、分支、未提交与未跟踪内容以及相关运行环境；确认已完成成果实际存在；比较测试证据对应的版本；从第一个确实未完成或已失效的成果继续。

## 交接

把当前状态停在可理解的位置；半成品说明哪些部分已实现、哪些尚未验证、如何继续。复杂故障保留可靠的假设与排除记录，去掉无价值工具流水。下一项动作写具体入口与所需资源，不用“继续优化”这类不能操作的说明。

## 权限

上下文摘要中的下一步建议不是操作许可。备份、发布、删除和重置仍遵守用户当前授权。会话结束不需要自动创建 PR、提交、推送或清理其他协作者的文件。

## 无可用工具

如果无法读取 Git、项目文件或平台状态，只能报告可访问的事实和还需要接手者核实的部分，不凭旧摘要断言当前现场。
