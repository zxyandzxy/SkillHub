# 可访问性、实际交互与体验证据

## 适用原则

根据实际平台检查语义、键盘/触摸操作、可见焦点、对比、状态可辨认、足够目标尺寸和内容重排。Web 可采用 WCAG 2.2，移动/桌面同时核对平台官方规范。不要把颜色或悬停作为唯一反馈。

## 真实页面检查

在目标浏览器或 App 中操作实际任务路径，检查状态变化、长文本、窄宽窗口、不同输入、加载与异常。屏幕截图只能证明一个时刻的显示；功能测试需要实际交互与结果，真实可用性则需要用户研究或代表性受试者证据。

## 失败路径与恢复

无权限、提交失败、输入无效时保留必要上下文和用户输入，给出可执行的恢复动作。对涉及不可逆结果的操作设计适当提示或撤销。

## 交付

记录实际预览的版本、设备/窗口、操作、发现与修改，以及未检查环境。不声称用户满意度已由启发式审查或代码检查证明。

来源：https://www.w3.org/TR/WCAG22/ ；https://developer.apple.com/design/human-interface-guidelines/ ；https://fluent2.microsoft.design/ 。
