# 计算机科学研究中的文献发现、深读与证据综合

科研文献调查的目标是回答一个具体的知识问题：目前哪些工作已经解决了相关任务，它们在什么假设与评价条件下成立，尚有哪些限制足以影响新研究的判断。搜索结果数量并不直接衡量文献研究质量。真正重要的是能否找到最近竞争工作、核验核心证据，并将不同论文中的机制、任务和结果放到可解释的比较框架中。

在 AI 和软件工程领域，同一个研究问题可能出现在机器学习、程序分析、软件测试和人机交互等不同社区中，术语又会随时间改变。依赖单一关键词、只看论文摘要或把某个 arXiv 版本当作全部正式研究，容易遗漏决定研究定位的相关工作。

## 一、从研究问题构造检索范围

### 先确定研究对象与决策目标

检索之前先说明需要回答什么问题，例如“仓库级 Issue 修复是否一定需要自主工具调用”“哪些上下文信息可以改善代码生成”或“现有 Benchmark 的通过测试能证明何种功能正确性”。每个问题都具有任务对象、方法机制、评价设置和可能的反例。先把这些要素拆开，可以得到比单个热门名词更有效的检索词。

例如搜索软件修复 Agent，仅使用 `agent` 可能遗漏 `automated program repair`、`issue resolving`、`repository-level repair` 或特定补丁生成术语。反过来，把所有关键词用 AND 连接也可能只找到标题高度匹配的小样本。检索应从宽泛的代表性工作出发，根据真实论文使用的术语逐步收窄，并为不同数据库调整检索式。

检索范围还受研究决策驱动。若用户只询问某篇论文中怎样计算成本，直接打开论文相应表格和附录即可；若要判断新方法与最近工作的差异，则需要搜索竞争机制、追溯引用并检查发表时间。

### 学术搜索的覆盖差异

会议官方 Proceedings 或出版商页面适合核实正式发表身份；领域数据库和引用索引适合发现相近主题及后续论文；arXiv 和作者预印本可提供更容易访问的全文，但版本和正式发表状态可能不同。作者 GitHub 项目可以帮助理解实现，不能单凭 README 证明论文的理论主张或发表结果。

对直接影响判断的文献，应记录正式标题、作者、发表会议/期刊、日期、版本和 DOI（若有）。当同一成果存在预印本、会议论文和期刊扩展版时，应核查新增内容或实验改变了什么，避免把它们当作三个独立方法。

## 二、以种子文献和引文追踪扩大覆盖

### 什么时候需要前后向追踪

具有代表性的种子论文通常提供两种入口。参考文献告诉读者该机制的理论与方法来源；被引文献则可以发现后续纠错、扩展和最新比较。对于模型架构，前向引用可能提供后续优化；对于系统基准，后续评价研究可能指出数据污染、协议缺陷或更合适的统计单位。

例如 [SWE-bench（ICLR 2024）](https://proceedings.iclr.cc/paper_files/paper/2024/file/edac78c3e300629acfe6cbe9ca88fb84-Paper-Conference.pdf) 构造了真实 GitHub Issue 与对应代码仓库的修复任务。若研究自动修复工具，SWE-bench 是任务与评价的重要来源；[SWE-agent](https://arxiv.org/abs/2405.15793) 探讨 Agent-Computer Interface；[Agentless（FSE 2025）](https://lingming.cs.illinois.edu/publications/fse2025.pdf) 研究一种不采用自主多步工具决策的实现路径。沿着这个关系阅读，可以区分“研究的是评价环境”与“研究的是执行机制”，而不把所有论文都当作同一种算法。

当发现的工作来自相邻领域时，应继续核查其实际任务定义。例如语言模型生成单函数代码与修改大型 Python 仓库都叫代码生成，二者需要的上下文、验证环境和评估单位差别很大。只按共同关键词分组会产生虚假的方法排名。

### 搜索何时可以停止

文献调查不应在“已找到十篇”时机械停止，也不能无限检索到每一个边缘主题。更有依据的停止条件是：已覆盖当前决策所需的核心任务和机制分支，直接竞争工作已深读并经过引用追踪，新增检索结果反复落在已筛选的研究簇中，未解决的不确定性不会改变当前研究选择。正式系统综述如需宣称穷尽覆盖，则需要单独的检索协议与可复现筛选记录。

## 三、阅读深度由论文的作用决定

有些论文是当前 Idea 的直接竞争者，需要核查方法、实验协议、附录和必要代码；有些论文只提供一个定义，定位对应段落即可。可以将工作按当前问题的相关性分层：P0 是可能改变新颖性或方法必要性的最近工作，P1 是关键机制或 Benchmark，P2 是间接背景，P3 是暂时无关材料。这种分层表示阅读投入，不是对论文科研质量打分。

深读一篇方法论文时，需要区分至少五方面：论文试图解决的具体问题、系统在推理阶段允许看到什么、核心机制怎样工作、采用何种数据/指标/统计单位验证、真实结果能够支持什么结论。文献中的“作者认为”与实验已显示的观察应在记录中分开。

例如 Agentless 在 SWE-bench Lite 上报告 300 个问题的修复结果，但这不等于所有自动软件修复系统在相同模型、成本和信息条件下得到的排名。比较若涉及模型版本、任务子集、采样预算和修复验证差异，就应在相应维度注明，而不是直接把论文表格中的最好数字相减。

## 四、从逐篇阅读到跨论文判断

一个有效的跨论文比较表应围绕研究问题设置字段：任务范围、关键输入、主要机制、运行时信息、比较条件、最强证据和已观察限制。写成综述时，先说明为何选择这些维度，再综合每类方法的共同机制与差异。逐篇抄写摘要并不能自动完成研究定位。

为重要主张建立精确来源定位也十分必要。说明“SWE-bench 使用真实 Issue 和 PR 构造任务”，应指向其正式论文中任务构建部分；说明“Agentless 采用固定阶段”，应引用方法描述和相应代码版本；说明“某种方法成本低”，则需要核查成本定义、模型收费时点和任务配置。来源本身可能更新，因而研究结论需要附上实际读到的版本与对应位置。

文献检索有天然的负面证据限制。没有找到一篇近似论文，可能来自术语差异、数据库覆盖、未公开工业实践或检索深度不足。科研的新颖性判断应表达为“在当前已核查的最近工作范围内发现何种差异”，保留继续查验的可能，避免直接宣称“世界首次”。

本文使用的论文关系可在以下正式来源核查：[SWE-bench, ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/file/edac78c3e300629acfe6cbe9ca88fb84-Paper-Conference.pdf)；[SWE-agent, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/5a7c947568c1b1328ccc5230172e1e7c-Paper-Conference.pdf)；[Agentless, FSE 2025](https://lingming.cs.illinois.edu/publications/fse2025.pdf)。正式出版元数据、具体表格和仓库代码的对应关系应在使用时进一步核实。论文自身是科学问题和方法的证据，数据库检索技巧来自可重复的信息检索实践；两类证据不应混为某种 Skill 自动改善效果的实验结论。

## 六、研究结论如何形成 `literature-research` Skill

前文的知识组织要求对应三类可执行能力：按当前科研决策形成检索范围、为关键主张定位可信原始来源、根据比较结果而不是论文数量决定是否继续搜索。入口 [SKILL.md](../../../skills/research/literature-research/SKILL.md) 将这三项工作连接为可根据任务裁剪的流程。

| 研究认识 | Agent 的具体行动 | 对应文件 |
| --- | --- | --- |
| 单一关键词容易遗漏相邻研究（第一节） | 将任务、机制和条件拆成多个检索维度，按数据库调整词组 | [discovery-and-evidence.md](../../../skills/research/literature-research/references/discovery-and-evidence.md) |
| 种子论文可定位前作及后续竞争者（第二节） | 选择影响研究决策的论文进行前后向引文追踪与版本去重 | [discovery-and-evidence.md](../../../skills/research/literature-research/references/discovery-and-evidence.md) |
| 重要论文需要不同的阅读深度（第三节） | 按 P0–P3 相关性分层，深读直接竞争工作 | [reading-and-synthesis.md](../../../skills/research/literature-research/references/reading-and-synthesis.md) |
| 综述应比较真实任务与机制（第四节） | 建立跨论文任务、输入、方法和证据的统一比较轴 | [reading-and-synthesis.md](../../../skills/research/literature-research/references/reading-and-synthesis.md) |
| 文献负面搜索不能证明全球新颖（第二、四节） | 记录检索覆盖和盲点，停止时说明未覆盖条件 | [SKILL.md](../../../skills/research/literature-research/SKILL.md) |

本 Skill 负责建立论文证据基础，不代替研究者决定哪些 Idea 值得研究；需要从现有不足形成或挑战机制时，应转向 `research-ideation`。运行时只对当前文献问题读取必要参考，不为每次查证一条引用而建立整套研究数据库。
